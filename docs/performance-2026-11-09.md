# AnyVis 第四轮：按需加载与启动体积

日期：2026-11-09（北京时间）。前三轮修复已通过 PR #2 合并到 main，合并提交为 `372965b387213b76f7ad447250a8cdae2ca05087`。本轮继续优化启动加载，不增加 API 覆盖计数，也不发布新版 Release。

## 改动

此前 Studio 静态导入并挂载全部工具窗口，即使窗口关闭，部分曲面网格等初始化计算仍执行。现将 19 款工作台、快捷键帮助、代码编辑器和时间轴改为首次使用时加载。工具第一次打开后保留挂载及原有关闭行为，关闭再打开不会丢失已选参数；未打开的工具不运行初始化。

加载过程有局部状态提示；窗口在加载期间可关闭或按 Escape 退出，稍后加载完成不会自行弹回。网络或模块加载失败显示局部错误，可重新尝试加载，不需要刷新整个编辑器。React.lazy 会缓存失败的 Promise，因此重试使用新的 lazy 实例，而非仅重置错误提示。

构建配置使用显式分包，避免 Vite 共享加载函数被归入 Three.js，导致 Studio 间接加载 Three.js 和 Math.js。CodeMirror 的 basic-setup 扩展与主体归入同一包，消除循环分包。新增 `scripts/check-studio-bundle.mjs` 随 `npm run build` 执行，验证可选大包未进入首屏依赖、所有延迟资源存在、没有静态循环分包；桌面 CI 会执行同一检查。

## 同环境构建对比

统计 `index.html` 与 Studio 入口的静态依赖闭包，去重并计入其 CSS，不计尚未触发的动态导入。前后均为本机相同依赖的生产构建；十进制 kB。gzip 是构建体积估算，不代表运行中的服务启用了 gzip，也不是加载耗时或内存测量。

| 首屏资源 | 优化前 | 优化后 | 变化 |
| --- | ---: | ---: | ---: |
| JavaScript 原始体积 | 6,743.56 kB | 4,161.83 kB | -38.3% |
| JavaScript gzip | 1,360.95 kB | 617.51 kB | -54.6% |
| CSS 原始体积 | 185.79 kB | 88.44 kB | -52.4% |
| CSS gzip | 30.68 kB | 17.70 kB | -42.3% |

首屏依赖不再包含 CodeMirror、时间轴库、Three.js、Math.js 和工具窗口。API registry 与 Blockly 仍为首屏大包，因此大分块警告仍存在；完整安装包体积不会减少相同比例。

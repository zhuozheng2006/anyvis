# AnyVis v0.1 架构与范围

AnyVis 的目标是制作可以“播放—暂停探索—继续”的交互课件。v0.1 将二维/三维场景、参数关系、时间编排和代码扩展放进一个本地浏览器编辑器。它是可扩展的工程起点；当前对象和操作范围有限，还不能可视化任意主题。

## 一份项目，多个编辑视图

`src/core/types.ts` 定义可序列化的 `Project`。项目包含维度、总时长、参数、对象、节点与连线、动画片段、交互节点、Blockly 工作区和代码扩展。编辑器不保存渲染库的内部对象，因此 JSON 可以作为长期场景格式的起点，也可以将来作为 AI 生成内容的接口。

| 层 | 当前职责 | 实现 |
| --- | --- | --- |
| 场景对象 | 圆、点、向量、函数曲线、立方体、球体及其外观/变换 | 自有轻量数据模型 |
| 参数与关系 | 数值参数、时间、公式、对象属性绑定 | React Flow + 有向图求值 |
| 动画编排 | 数值参数片段、线性/平滑插值、交互停顿 | 时间轴编辑器 + 纯函数求值 |
| 积木编排 | 将动作、等待、交互和组合编排转换为时间轴 | Blockly |
| 实时画面 | 二维 SVG、三维 WebGL | 浏览器 SVG + Three.js / React Three Fiber / Drei |
| 数学表达式 | 数字、变量、限定的运算符和数学函数 | mathjs 解析与编译 |
| 代码扩展 | 可选 JavaScript 对现有对象进行逐帧修改 | CodeMirror + Web Worker |

节点图管理“一个量如何依赖另一个量”；积木管理“先做什么、同时做什么、何时暂停”。积木需要显式应用到时间轴。当前不是任意代码与节点、积木之间的无损双向转换系统。

## 可任意拖动的基础播放模型

基础场景求值使用 `evaluateProject(project, time, overrides)`：

1. 从参数默认值出发，按片段开始时间及同起点时的项目顺序，计算该时刻的参数值。
2. 已经开始的片段提供插值值；片段结束后保留终值，直到后续片段接管。尚未开始的片段不改变当前值。同一参数的片段若重叠，开始更晚的片段优先；同起点时项目中后列出的片段优先。
3. 应用观众手动调整的参数。手动值优先于时间轴，并限制在参数范围内。继续播放不会自动取消手动值；“释放”交还时间轴控制，“回到开始”清除手动覆盖。
4. 按拓扑顺序计算节点，并将绑定结果应用到一份新的对象数组。

基础模型是纯函数：同一项目、同一时刻、同一参数覆盖，应得到相同场景。反向拖动时间轴不需要倒放历史命令，前后跳转也不会累积数值误差。参数本身由时间驱动，不提供物理积分器。

公式节点的 `a`、`b` 来自端口连接，还可以读取时间 `t` 和参数 ID。这些全局参数引用目前直接读值，没有自动生成对应连线。公式编译结果有上限缓存；普通场景每帧重新求值，尚未实现精细的增量更新。

## 依赖图与异常处理

节点与边采用邻接结构。`src/core/scheduling.ts` 中的 `topologicalSort` 使用 Kahn 算法：先计算入度，零入度节点入队，再逐步减少后继入度；队列使用游标，避免反复 `shift()`。时间和空间复杂度均为 **O(V + E)**。未能输出全部节点表示存在循环依赖。

每个输入端口只接受一个来源。公式出错、缺失输入、非有限实数、上游计算失败或重复属性绑定会进入错误列表；失败结果不会继续写入对象。图本身出现循环或悬空连线时，整张图停止应用，对象保留基础状态。数学表达式只接受限定 AST 节点，不开放赋值、属性访问、数组和任意函数调用。

当前参数片段求值先排序，再为每个参数遍历片段。因此参数数目为 P、片段数为 C 时，相关工作为 **O(C log C + P·C)**；节点部分为 **O(V + E)**，此外还要计入公式求值和曲线采样成本。原型规模下先追求语义清楚，后续可以为每个参数建立片段索引，并缓存不变图的拓扑序。

## 交互停顿

交互节点包含时间、标题与引导说明。播放循环比较前后两个时刻，找到尚未访问的第一个交互节点，精确停在其时间；即使某一帧跨越多个节点，也优先停在最早的节点。访问记录属于运行时状态，用于继续播放时避免立即重复触发同一个停顿。

暂停时修改参数会重新求值当前时刻。恢复播放后沿相同时间轴继续。交互节点目前不是条件分支，不会根据用户回答跳到其他章节；也没有测验判分、循环授课或网络协作。

## 代码扩展的边界

扩展函数接收 `t`、`params`、`objects`，同步返回全部现有对象组成的数组。可以修改有限数值的变换、颜色和可见性，不能在此接口增删对象或改变对象类型。扩展运行在 Worker 中；超时和返回值校验用于避免一次错误阻塞主界面，导入或恢复项目后需要手动启用扩展。

基础场景的确定性不自动扩展到任意 JavaScript。使用随机数、当前日期或脚本内部状态时，回到同一时刻可能得到不同结果；要保持可拖动时间轴的行为，扩展应编写成输入到输出的纯函数。Worker 计算是异步的，复杂扩展可能产生预览延迟。Worker 也不等于面向恶意代码的完整安全沙箱。

## 保存与当前范围

浏览器本地草稿自动保存；导出的 `.anyvis.json` 可以重新打开。导入检查版本、数据规模、有限数值、ID 唯一性、引用和图结构。普通对象、节点、连线、片段及交互节点支持 UUID；参数 ID 需要满足数学表达式的变量命名规则。

草稿允许暂时留空的显示名称和表达式，避免用户编辑到一半后重新打开就丢失工作。空表达式会在求值时提示错误。动画片段结束边界有浮点容差，允许 `11.9 + 0.1` 这样的正常十进制编辑。

已实现的工程范围包括二维/三维示例、对象属性、参数联动、节点连线、片段拖动和插值、交互停顿、积木编译、代码扩展、撤销重做与项目 JSON。尚未实现 Manim 导出、视频导出、独立离线课件打包、任意代码导入、多场景章节、复杂约束求解、物理模拟、通用标签排版和 AI 服务接入。二维函数曲线当前在固定区间进行有限采样，极点、不连续点和高频函数仍需进一步处理。

## 课程项目可以深入的内容

值得重点解释和验证的算法是依赖图拓扑求值、环检测、时间轴确定性求值，以及嵌套积木到片段/交互节点的递归编译。撤销重做使用有界历史栈，项目保存使用结构序列化。成熟库负责编辑器交互、数学语法和图形显示，课程核心仍是统一语义、错误处理和可验证的算法。

后续实验可以比较不同 V/E/C 规模下的求值耗时；对同一场景按随机时间顺序求值，验证与顺序播放的数学状态一致；构造循环、冲突绑定、无效表达式和跨帧交互节点检查错误行为。性能报告应同时给出浏览器和硬件条件，不以“实时”一词代替具体测量。

## 本次验证状态

原生 Node 的 TypeScript 去类型解析已检查核心文件语法。`node scripts/check-scheduling.mjs` 直接执行实际调度模块，42 个断言通过，覆盖拓扑顺序、环检测、线性/平滑插值、重叠优先级、反向跳转确定性、参数覆盖、零秒停顿和继续播放。另一次离线 smoke 检查通过：两个示例的导入检查、拓扑顺序及环检测、UUID 与编辑中草稿的 JSON 往返、十进制片段结束边界、片段插值、手动参数优先级、零秒交互节点及访问记录。

上述离线检查明确跳过了 mathjs 表达式执行。依赖下载受当前环境网络限制，完整 TypeScript 类型检查、Vitest、Vite 构建、浏览器 UI 与 WebGL 实测仍待安装依赖后执行；不能将离线检查等同于整套应用已运行通过。

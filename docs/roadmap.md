# AnyVis 开发路线

定位：面向科学教学的交互可视化编辑器。作者以场景、关系和讲解流程表达意图；观众在运行中调整参数。代码是可选扩展入口，基础创作不应依赖代码。

## 当前阶段：验证编辑器闭环

已编写二维 / 三维场景、真实节点图、真实积木、时间轴、交互暂停、代码扩展及项目保存。当前优先级是安装依赖后修完编译和浏览器问题，完成下述三个端到端验收：

1. 单位圆与正弦曲线：播放到交互节点 → 修改半径 → 继续 → 倒退跳转 → 保存重开。
2. 空白二维课件：添加参数和对象 → 在节点图连接参数到尺寸 → 用积木编排参数变化与暂停 → 播放。
3. 三维轨道：旋转相机 → 修改参数 → 在代码扩展中改变对象变换 → 制造超时并确认编辑器仍响应。

## 下一阶段：提高作者体验

- 编辑面板可伸缩、节点 / 积木全屏、二维平移缩放与三维变换操纵柄。
- 参数、属性与图形直接双向编辑；明确区分基础值、动画值、手动探索值。
- 可配置坐标系范围和曲线定义域、采样自适应与断点处理。
- 公式与标签：采用 KaTeX 或 MathJax 排版；跟随对象、自动避让。
- 时间轴片段碰撞提示、多选、复制与层级轨道。
- 作品列表与备份，避免只有一个浏览器草稿。

## 内容与复用

- 割线逼近切线、黎曼和、线性变换、BFS 等首批领域组件。
- 参数化复合对象、子图与子时间轴，可以展开修改再保存。
- 对象注册机制统一 2D / 3D 适配器与组件 schema。
- 拖动积木时静态检查，选择节点时显示依赖路径与错误根因。

## 交付与扩展

- 导出独立可交互 HTML 课件，保留暂停节点和参数控件。
- 同一播放器离线逐帧采样，再接成熟编码器导出视频；视频不保存交互能力，需分别定义交付格式。
- 再评估 Manim 作为高质量导出后端，先明确支持子集与一致性测试。
- AI 生成受校验的项目数据，进入现有编辑器；暂不做任意 Python 逆向转换。

## 课程实验

- 拓扑排序 / 更新成本随 V、E 增长的曲线；比较全图重算与依赖失效传播。
- 编排树展开及区间冲突检测，记录复杂度与边界情况。
- 同一时刻正向播放、反向跳转和直接求值的一致性。
- 对比 AI + Manim，测首次制作、替换参数、调整节奏的耗时和错误率。

这些是路线而不是已完成承诺。先证明一个完整课件可编辑、可探索、可重新打开，再扩大对象类型。

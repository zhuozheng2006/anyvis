# v0.5.2 创作界面与积木设计

## 调整依据

在 1126×819 的窗口中，原快捷添加栏文字换行并越出容器，预览与属性比例固定，属性区被限制为 115px，坐标辅助面板挤进 y 字段。对象列表位于属性下面，选择对象和编辑属性需要来回寻找。顶部有重复工作台入口。常用积木中的“移动到”隐藏部分坐标，“对象出现 / 准备”不说明对象类型，“前移图层”实际改变创建顺序。

## 本轮设计

1. 保持左侧编排、右侧预览与对象管理的结构，增加两个分隔线；支持拖动、方向键、Enter 和双击复位，并保存个人比例。窄窗口上下排列。
2. 对象列表在上、属性在下，属性独立滚动。常用数字输入扩大，坐标保持同一组。九宫格定位和动态参数折叠；预览中的辅助线和背景收进“画面辅助”。
3. 常用积木按创作目的分为出场与退场、移动与变形、强调与指示、时间与顺序、外观与排布、参数与跟随、三维镜头，以及高级扩展。高级 API 仍保留浏览与搜索入口。
4. 移动和位移始终显示目标对象、三个方向的数值和时长。将缩放解释为相对当前大小的倍率，将不透明度端点与往返效果说清楚。参数说明可悬停查看。
5. 变更只涉及呈现、交互及提示，不迁移工程字段；已有的对象引用、参数数值、嵌套动作、折叠状态和草稿继续往返保存。

## 验证

- 应用测试：107 个文件、646 项通过，新增完整坐标展示、动作分组与搜索、对象提示、键盘调整与布局持久化回归。
- 生产构建通过；11 项桌面测试和 2 项发布流程测试通过。
- Chrome 实测 1440×900、1126×819 和 780×900；验证实际拖动分隔线、键盘调整、工具栏、积木库、对象属性与时间轴。完成现有三秒圆形工程的真实 Manim 预览。
- macOS / Windows / Linux 安装包与原生 Manim 检查由该提交的 GitHub Actions 继续验证，Release 流程只接受同一提交全部通过的构建。

尚待进一步改善：大量对象的列表导航、长工程的积木导航，以及高级 API 的中文引导。这一轮没有把 755 项未验证 API 标记为已完成。

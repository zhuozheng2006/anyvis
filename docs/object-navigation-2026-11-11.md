# 对象导航与 README 整理（2026-11-11）

本轮延续 v0.5.2 的界面调整，重点处理对象较多时的查找与选择。

## 改动

- 对象分类改用目录中的对象类型，不再通过名称中的 circle、line 等片段猜测。椭圆、球体不再漏出图形分类，数轴与三维坐标系归入坐标，动态数字归入文字。
- 删除对象导致数量降低时，正在使用的搜索和分类仍保留。显示结果数量与空结果提示，可一键清除筛选；搜索框按 Escape 清空关键词。
- 过滤不会暗中切换当前编辑对象。属性区显示对象名称，选中对象不在结果中时提供“显示当前对象”入口。
- 对象选择改为原生按钮，避免按钮角色嵌套；方向键、Home、End 可导航对象。外部选择会滚动显示对应卡片，但不会抢走输入焦点；修改对象参数也不会反复触发滚动。
- README 改为产品介绍、四项主要特点、第一段动画的操作步骤、桌面下载与源码启动。历史轮次、测试计数、工具清单和实现细节移出首页。

## 验证与边界

107 个测试文件共 652 项应用测试通过；11 项桌面测试、生产构建、README 本地链接检查与 git diff --check 通过。新增回归覆盖分类、删除后的筛选恢复、切换项目、键盘导航、焦点保持与滚动时机。

本轮交互验证使用 jsdom 组件测试，没有进行浏览器视觉实测。原生按钮的 Enter/Space 行为由浏览器提供，测试没有将 jsdom 的模拟键盘事件当作浏览器实测。未改动渲染逻辑或 API 覆盖声明。

本轮更新 main 源码与文档；公开安装包仍为 v0.5.2，没有覆盖已发布的安装文件。

# AnyVis：验收问题修复与复验记录

日期：2026-11-09。对应 [独立验收](acceptance-2026-11-09.md) 中发现的问题；初始代码为 `fd46a5c`。本记录描述当前修复，不追认旧 v0.5.0 tag 的质量声明。

## 结论

本轮修复已通过 **623 项应用测试（104 文件）**、生产构建和桌面资源准备；新增原生检查覆盖切分/复制语义、55 个数学预设/模式及 19 个向量、积分、配色、字幕和镜头场景。完整 API 原生测试 **30/30** 通过，重新生成的 12 份证据全部通过当前指纹校验。

这不等于完整 Manim API 覆盖或所有工作台视觉效果完全一致。音频分析、自定义缓动直接应用、完整逐帧视频等边界见后文。构建仍有大分块警告，本轮未新打包三平台安装器，未重新进行 OpenGL 像素验证。

## 已修复内容

第三轮新增：标记元数据不再使视频过期；H.264 后备转码支持 AAC 配音/钢琴，缺 AAC 时保留完整 WebM。浏览器已实测添加标记并改名，自动保存后仍显示“播放已生成的动画”。媒体闭环实际输出 H.264/AAC MP4，48 帧解码通过，配音约 0.503 秒开始、1.0003 秒结束，切分接缝连续，660 Hz 音调保持。

## 工作台的当前交付边界

- 曲面、概率密度/概率质量、极坐标和参数曲线均生成真实几何，保留所选数学参数。曲面不保证与浏览器示意图的投影或配色逐像素相同。
- 傅里叶导出保留所有谐波的重建轨迹，尚未生成浏览器中的旋转圆盘；流线使用固定采样路径，不复制浏览器随机粒子过程。
- 黎曼和区分左、右、中点与梯形，生成实际对应的分划几何。
- 字幕和运镜追加为独立片段，时间从追加片段开头计算，界面已说明；未自动叠加到已有视频时间轴。字幕支持重叠显示及准时移除。运镜当前限二维 Cairo；不支持的场景会明确报错。
- 彩色公式使用实际 MathTex 和加载 xcolor 的 TexTemplate，验证字形保留配色；保留已有可信扩展运行授权，未绕过安全规则。
- 音频频谱仍为**合成数据模拟预览**，未接入真实音频分析，插入和导出已明确禁用。原有上传配音、默认钢琴与无声功能不属于这项模拟器限制。
- 自定义贝塞尔曲线可预览及导出 Python，工程内仅能直接应用匀速。章节 Python 明确是**不含工程对象/动画的骨架**，章节标记可同步到工程。
- 自动布局处理嵌套对象并清除旧 workspace；不把普通动画的坐标字段当成可排版对象。

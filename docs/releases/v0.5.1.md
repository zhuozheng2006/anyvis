## 更新内容

本版同步 main 上的六轮修复与优化，替代只有说明、没有安装包的 v0.5.0 下载入口。

- 修复动画切分改变最终结果、组合复制引用原对象、框选失效，以及缩放舞台后拖动物体跳变。
- 修复工作台参数丢失、无效动作、章节标记保存丢失；标记修改不再使视频过期。
- 19 款工作台、代码区与时间轴按需加载，首屏 JavaScript gzip 约从 1.36 MB 降至 0.62 MB。
- 图片与配音支持真实视频导出；缺少 libx264 时可通过 libopenh264 输出带声音的 MP4。
- 素材操作超限时保留原工程；未完成草稿仍可保存 ZIP；Python 源码导出严格校验。
- 当前作品记录缺失或损坏时可从作品库恢复；重新打开同一作品的备份会清空旧撤销历史。

## 下载与运行

| 系统 | 安装包 |
| --- | --- |
| macOS Apple Silicon | `AnyVis-0.5.1-mac-arm64.dmg` 或 `.zip` |
| macOS Intel | `AnyVis-0.5.1-mac-x64.dmg` 或 `.zip` |
| Windows x64 | `AnyVis-0.5.1-win-x64.exe` |
| Linux x64 | `AnyVis-0.5.1-linux-x64.AppImage` 或 `.deb` |

所有安装包来自同一次通过检查的三平台构建，附 `SHA256SUMS.txt`。桌面包包含编辑器与本地服务；渲染仍需另行安装 Python 和 Manim CE 0.20.1，并在桌面设置中选择相应 Python 环境。公式需要 LaTeX 工具及适当字体。

macOS 使用本地临时签名，尚无 Apple Developer ID 公证；Windows 尚无正式代码签名。系统可能提示发行者未经验证。本版不会绕过系统安全提示，也没有新增自动更新功能。

## 验证与能力边界

发布流程要求同一提交的原生 Manim 回归和三平台桌面检查全部成功，并在全部七份安装包与校验和上传后才公开 Release。浏览器媒体流程已经实际完成上传、裁剪、ZIP 保存重开和 720p MP4 下载；安装包通过打包后的应用启动检查。

有效 API 行为证据仍为 **1,538 / 2,293**，其余 **755** 尚待验证，不能视为完整 API 覆盖。真实音频频谱分析和自定义缓动应用尚未完成；具体边界见仓库中的验收与修复记录。

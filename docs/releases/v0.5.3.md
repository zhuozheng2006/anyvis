## 更新内容

本版改善对象查找、参数窗口和命令搜索的键盘操作，减少编辑过程中的误触。

- **修复弹窗与右键菜单冲突**：打开应用弹窗时关闭已有积木菜单，积木菜单和提示保持在弹窗下方；弹窗打开期间阻止后台工作区触发菜单。右键或中键点击画面设置等窗口、命令搜索的遮罩不再误关窗口，输入框仍保留浏览器的复制、粘贴菜单。
- **对象分类更准确**：椭圆、球体归入图形，数轴和三维坐标系归入坐标，动态数字归入文字。
- **筛选更容易恢复**：显示匹配数量和空结果提示，支持一键清除筛选；删除对象后仍保留清除入口，切换项目时重置筛选。搜索框按 Esc 可清空关键词。
- **当前编辑对象更清楚**：筛选不会自动切换选中对象；属性区显示对象名称，并在对象被筛选隐藏时提供“显示当前对象”入口。
- **对象导航更顺畅**：支持左右方向键及 Home、End 切换对象；从其他区域选中对象时，对应卡片会滚动到可见位置，同时保留输入焦点。
- **弹窗键盘操作更一致**：添加对象和全部参数窗口支持进入时聚焦、Tab 循环、Esc 关闭和关闭后恢复焦点。修复参数编辑器确认快捷键误触发后台预览，以及嵌套弹窗与后台快捷键冲突的问题。
- **命令搜索更易操作**：键盘选中的结果会自动滚动显示；改善焦点返回和屏幕阅读器关联，修复中文输入法确认候选词时误执行搜索结果的问题。

README 同时整理了产品介绍、入门步骤和下载说明；内部改进了构建依赖安装的超时、重试和诊断日志。

## 下载与运行

提供 macOS Apple Silicon / Intel 的 DMG、ZIP，Windows x64 EXE，Linux x64 AppImage、DEB，以及 `SHA256SUMS.txt`。

桌面包包含编辑器和本地服务；渲染仍需另行安装 Python、Manim CE 0.20.1，公式需要 LaTeX 和相应字体。

## 验证范围与已知限制

发布以同一提交通过三平台桌面构建检查和原生 Manim 回归为前提。新增交互通过 DOM 组件与逻辑测试验证，尚未完成本轮真实浏览器视觉验收，不能视为所有界面操作均已实测。右键修复包含真实 Blockly 弹出容器的生命周期测试，但 DOM 测试不验证浏览器绘制层级或系统右键菜单外观。

macOS Intel 包为交叉构建，尚未在 Intel Mac 上实际启动；安装向导和用户本机 Python 环境仍需独立验证。macOS 使用临时签名、尚未公证；Windows 尚无正式代码签名。

本版不新增 API 覆盖声明。仓库记录的有效行为验证基线为 1,538 / 2,293，仍有 755 项待验证；局部 OpenGL 检查不代表全部 OpenGL API 均已验证。

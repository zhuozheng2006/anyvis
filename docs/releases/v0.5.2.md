## 更新内容

这一版重新整理创作界面与常用积木，让对象、动作和预览之间的关系更清楚。

- 编辑区与预览区、预览与对象属性之间支持拖动调整；方向键可微调，双击或 Enter 恢复默认。比例自动记住，窄窗口改为上下布局。
- 顶部重复入口统一收进“创作工具”；快捷添加栏不再挤出区域。对象列表固定在属性上方，属性独立滚动，数字输入更易操作。
- 九宫格定位与动态参数按需展开，避免辅助工具挤占常用参数空间。对象卡片的“提前/延后创建”明确区分于画面叠放层级。
- 常用动作按出场退场、移动变形、强调指示、时间顺序、外观排布、参数跟随和三维镜头分类。
- “移动到指定位置”默认显示完整坐标；位移、缩放、不透明度和往返节奏使用更明确的描述。对象出场块显示对象类型，参数说明可通过悬停查看。
- 修复已有对象时积木库仍提示“先创建对象”、预览面板缩小后控件被裁切、坐标辅助面板挤入单个字段的问题。

工程数据格式和动画执行逻辑保持兼容，已有项目可继续编辑。

## 下载与运行

提供 macOS ARM64 / Intel 的 DMG 与 ZIP、Windows x64 EXE、Linux x64 AppImage 与 DEB，以及 SHA256SUMS.txt。发布流程只接受同一提交通过原生 Manim 回归与三平台桌面检查的完整安装包。

桌面包包含编辑器和本地服务；渲染仍需安装 Python、Manim CE 0.20.1，公式需要 LaTeX 和相应字体。macOS 使用临时签名，尚未公证；Windows 尚无正式代码签名。macOS Intel 包为交叉构建，尚未在 Intel 机器实际启动。

API 行为验证范围仍为 1,538 / 2,293，其余 755 项待验证；本版不新增 API 覆盖声明。

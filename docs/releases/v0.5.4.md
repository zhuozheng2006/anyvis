## 编辑与预览

- **时间轴保留编辑位置。** 首次渲染前即可定位和添加标记。预览元数据随后加载时，刚选定的播放头位置仍然有效。编辑位置超出旧视频时长时，视频显示末帧，标记仍落在编辑时间。
- **对象定位适配画幅。** 横屏、方形和竖屏工程的位置画板采用场景的实际比例。右击画板会保留对象坐标，正常拖动结束时提交新位置。
- **参数编辑更容易撤销。** 数值输入可以确认或取消，滑块一次拖动只产生一次修改。动态参数的自动命名会避开表达式保留字。

## 作品与配音

- “我的作品”可以搜索和排序，继续编辑当前作品时保留最新修改。较慢的导入在切换工程后完成时会保留后来打开的作品。
- 演播模式会检查预览是否对应当前积木。快捷键支持键盘激活按钮和中文输入法，播放被浏览器拒绝时会提示重试。
- 连续停止配音或重播同名素材时，时间轴、视频和导出的 Python 代码使用一致的播放区间。添加超过 600 秒的音频时，界面提示初始片段取前 600 秒，并保留完整源素材。

## 下载与运行

macOS 提供 Apple Silicon 和 Intel 两种架构的 DMG 与 ZIP，Windows x64 提供 EXE，Linux x64 提供 AppImage 与 DEB。可用随附的 `SHA256SUMS.txt` 核对下载文件。

桌面版内含编辑器与本地服务。渲染需安装 Python 和 Manim CE 0.20.1，公式还需 LaTeX。macOS 包使用临时签名，Windows 包尚无正式代码签名。[桌面环境配置](https://github.com/zhuozheng2006/anyvis/blob/v0.5.4/desktop/README.md)

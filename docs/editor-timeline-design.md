# AnyVis：对象管理器、积木、时间轴与只读代码

设计日期：2026-11-08。依据当前创作流程重新组织编辑器，继续保留完整 Manim API 接入。

## 工作区

左侧提供三个平级视图：**积木、时间轴、代码**。右上保持真实 Manim 预览，右下改为**对象管理器**，替换动画步骤列表。三个视图共享同一个作品、选择状态和撤销历史。

| 区域 | 负责什么 | 编辑结果 |
| --- | --- | --- |
| 对象管理器 | 添加图形、图片、文字、公式、坐标系等；命名、颜色、位置、几何参数及 API 参数 | 更新对应对象定义及引用，立即同步积木、时间轴和生成代码 |
| 积木 | 出现、移动、变形、隐藏、等待、顺序、并行、循环、回调等行为 | 时间轴重新计算；代码重新生成 |
| 时间轴 | 对象轨道、秒刻度、播放头、片段选择、时长调整、顺序调整、等待与并行编排 | 修改相同的动作树；积木和代码同步 |
| 代码 | 查看、查找、复制、导出完整 Python | 只读，不反向解析任意 Python |

采用三个标签页切换左侧工作区，避免把同一块有限屏幕再切成三个狭窄编辑器。预览和对象管理器始终保留。窄窗口上下排列，时间轴内部横向滚动。

用户提供的 Scratch 界面作为空间组织参考：左侧大工作区、右上舞台、右下对象卡片；选中对象后在卡片上方集中显示名称与位置等属性。保留 AnyVis 的配色和数学动画身份，不照搬 Scratch 的装饰或把对象改称角色。

## 共享模型与兼容性

现有 v2 `Project.actions` 已表达顺序、并行和重复，也是编译器的真实输入。第一版继续使用它作为唯一事实来源，增加视图投影，不引入第二套会与积木失同步的时间轴数据。

对象构造动作的**配置**只在对象管理器编辑；其在动作树中的位置表示“何时准备或显示该对象”，在积木中呈现为简短的对象出现动作。对象名称引用与嵌套 API 参数使用现有语义重命名逻辑，不能用全文替换。这样既满足界面上的职责划分，也保留旧项目中“先移动 A，再根据 A 的位置构造 B”的执行时机。

旧工程直接打开，不提前执行对象构造、不搬动动作顺序、不丢弃 Python 扩展或高级 API。新对象由管理器添加；普通积木工具箱不再展示图形和文字构造器。API 浏览器按用途提供对象构造入口和动作/逻辑入口。

## 时间轴组件选型与已落地范围

采用 MIT 许可的 [React Timeline Editor](https://github.com/xzdarcy/react-timeline-editor)，锁定 `@xzdarcy/react-timeline-editor@1.0.0` 与 `@xzdarcy/timeline-engine@1.0.0`。复用其 Interact.js 拖拽/缩放、虚拟列表、刻度、播放头、边缘辅助线、吸附与自动滚动；AnyVis 负责动作树映射、校验、撤销和真实 Manim 渲染。库只提供编辑器组件，不自带完整视频剪辑/混音产品。没有继续维护原先手写的片段拖拽控件。

已实现：独立配音轨、真实波形、源文件入点/长度、音量/静音、按帧吸附、时间轴缩放与适合全部、拖动排序和空白插入、动画右边缘时长调整、音频左右裁剪、播放头处分割配音、统一撤销，以及空格播放、方向键逐帧、Home/End 首尾定位、Shift + 方向键移动 10 帧、S 吸附等快捷键。片段选择区固定高度，避免拖动时布局跳动；隐藏积木的取消选择事件不能清空时间轴选择。

后续已实现框选与多选、批量移动/删除、复制与变速，以及保持结果一致的受限片段切分。仍需扩展完整关键帧曲线编辑、任意跨轨动画重叠、嵌套复合片段的时间轴内展开。当前动画使用顺序联动与显式并行，不宣称已经等同于 Premiere / DaVinci Resolve。

## 时间轴交互与真实语义

- 深色剪辑区，固定对象轨道标题、秒刻度、彩色动画片段和播放头；支持缩放、横向滚动、点击时间定位真实视频。
- 点击片段选中动作，显示对象、开始时间、时长及相关参数。拖片段调整顺序；拖右边缘调整时长；同时提供数字输入和按钮，保证键盘可操作。
- 顺序动作采用联动后移：前一段变长，后面的片段随之后移，不留下隐式重叠。等待也是明确片段，可添加、修改和删除。
- 并行和重复呈现为复合片段，显示真实累计时长；进入积木可编辑复杂结构。允许的并行组合仍由编译器检查，同一对象冲突不能静默接受。
- 任意时间重叠不直接等价于 Manim 的 `play`。首版不把拖动强制转换成语义不明的并行代码，也不通过固定 Python 片段模拟未实现的调度。
- 时长由动作语义决定。API、回调或 Python 导致的动态时长明确标注为“动态”，后续未知位置不伪装成准确秒数。零时长设置以事件标记表示，不强行变成一秒片段。
- 播放头操作只定位已生成的视频；项目修改后显示预览过期状态，避免将旧画面误认为当前效果。

## 对象管理器

对象卡片显示名称、类型和颜色，支持搜索、选择、添加及参数编辑。常用参数直接显示，复杂参数继续使用已有结构化编辑器。名称编辑同步更新普通引用、对象列表和嵌套 `$ref`；被引用对象的删除需要先处理使用它的动作，不能悄悄删除依赖。

坐标、大小、文本内容等属于对象配置；出现方式、出现时长属于动画配置。代码扩展、参数计算和 API 返回值继续在逻辑区处理，不能仅因为有“结果名称”就误当作可见图形。

## 撤销、保存与错误

统一项目级撤销/重做，覆盖对象参数、积木操作和时间轴操作；一次拖动或一次参数提交是一条历史记录。切换视图不改变作品。所有视图的改动进入现有自动保存、导出和渲染取消机制。错误保留到对应动作或对象的定位入口。

## 代码滚动修复

代码区域使用有明确高度的 flex 子容器；外层 `min-height: 0`，CodeMirror 填充剩余高度，内部 scroller 独立滚动。标题、导出按钮和权限提示不挤入滚动内容。验证长代码能滚动到末尾，并保持只读。

## 图片与配音素材（补充需求）

对象管理器增加上传图片和配音。素材需要有稳定 ID、原始名称、媒体类型、尺寸或时长，文件由本地服务保存；不能把任意用户路径直接当成已上传素材。导入缺失素材的工程时明确提示缺失，不能悄悄使用同名文件。

图片优先支持带透明通道的 PNG、JPEG、WebP 和矢量 SVG。像素图片使用 Manim `ImageMobject`，矢量图使用 `SVGMobject`；支持对象的平移、缩放、旋转和透明度动画。单张图片仅作为整体运动；角色表情或肢体需要分层素材或矢量部件，不能声称上传位图后自动获得骨骼与表情。

配音使用独立音轨，可播放试听、调整开始时间、裁剪入点/出点、增益和静音。积木提供“开始播放配音”“停止播放配音”，时间轴编辑与这些动作共享状态。视频导出必须包含真实混音，不能只在浏览器预览时叠放 HTML 音频。源文件保持不变，裁剪是工程元数据。首先支持上传已有配音，不默认调用收费 TTS。

素材上传、保存、渲染与导出一起验收：文件格式/大小校验、路径隔离、项目中的素材引用、服务重启后仍可用、真实输出视频的音轨与时序，以及无声旧项目兼容。音频轨道的绝对时间需要与动作树的等待/播放事件建立明确映射，不能把任意音频片段误当成占用动画执行线程的等待。

## 实施与验收顺序

1. 修复代码滚动；实现动作/对象分类、时间计算、重排与时长更新等可独立测试的模型操作。
2. 实现时间轴及参数面板；接入共同的选择、撤销、自动保存和代码生成。
3. 用对象管理器替换右下步骤列表；限制积木区的构造参数编辑，将对象添加入口移到管理器。
4. 旧模板、嵌套顺序/并行/重复、API 对象及动态时长回归。验证重命名、删除引用保护、撤销/重做、视图往返和重新导入。
5. 浏览器验证对象创建→改参数→添加动画→时间轴调整→积木同步→代码导出→真实渲染；桌面构建及已有 API 回归测试继续通过。

验收不能只看时间轴外观。修改时间轴必须改变生成代码和真实视频；旧工程在未编辑时的执行顺序、时长和权限要求应保持不变。

## 素材可移植与实际验证

含素材的工程保存为 `.anyvis.zip`，包含原始素材、项目 JSON、可生成时的独立 Python 源码；导入先校验内容散列，再由服务验证实际媒体。无素材工程沿用 JSON。压缩包上限 128 MB，单文件 64 MB。

音频由 PyAV 解码、按入点裁剪为 PCM 后交给 Manim 混音，不依赖额外的命令行 ffmpeg。透明图片兼容 Pillow 13 的修正局限在导出场景的 Manim Camera 适配器内，不修改用户环境。真实回归验证透明图片位移、压缩 OGG 配音裁剪、延时、增益和停止播放后的静音；浏览器验证素材包保存和重新打开、音轨拖动/裁剪及撤销重做。

## 默认配乐

新建作品默认选择“自动钢琴 · 平静优雅”，也可选“无配乐”；选择同步成为以后新作品的默认偏好，已保存/导入工程保留原设置。背景音乐独立于上传讲解，默认 -18 dB，可调音量；时间轴显示自动铺满的只读配乐轨，点击可更改设置。入口位于时间轴工具栏、对象管理器与画面设置。

配乐由本地确定性合成器创作与生成，使用舒缓和弦、琶音与钢琴泛音衰减，不联网、不引用第三方录音。按实际渲染时长生成并首尾淡入淡出，包含在独立 Python 导出中；选择无配乐时不生成音乐音轨。它是合成钢琴，不是钢琴录音库或外部生成模型。

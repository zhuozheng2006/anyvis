# AnyVis

一个面向数学、物理、计算机与 AI 教学的交互可视化编辑器。目标是让作者编排动画，让观众在讲解中的交互节点停下来调整参数，然后继续观看。

当前是 **v0.1 开发原型**：已经编写共享场景模型、编辑器和实时播放器。当前执行环境无法连接 npm，尚未安装依赖；完整构建和浏览器操作验收仍待完成，不能视为已验收产品。

## 启动

需要 Node.js 22.12+（Node 24 LTS 也可以）和 npm。首次安装需要联网。

```sh
cd AnyVis
npm install
npm run dev
```

打开终端显示的 `http://127.0.0.1:5173`。也可以在 macOS 双击 `start-anyvis.command`。安装依赖后会生成 `package-lock.json`，应将它一并纳入版本管理，后续使用 `npm ci`。

验证命令：

```sh
npm test
npm run build
```

不需要 npm 依赖的部分检查（Node.js 22.18+ 的原生 TypeScript 支持）：

```sh
node scripts/check-extensions.mjs
node scripts/test-block-program.mjs
node scripts/check-scheduling.mjs
```

`node scripts/check-syntax.cjs` 会使用已安装的 TypeScript，或本机 VS Code 附带的 TypeScript 做语法检查。**它不能替代完整类型检查、打包和浏览器验收。**

## 已编写的功能

- **二维 / 三维场景**：新建空白项目或示例；添加、隐藏、删除对象，修改属性；二维 SVG 和 Three.js 三维预览。
- **参数探索**：管理数值参数，拖动滑块实时更新关联对象；手动调整覆盖轨道，点击“释放”恢复时间轴控制。
- **时间轴**：参数动画、线性 / 平滑缓动、拖动片段、缩放时长、任意时间跳转；交互旗标暂停，点击继续恢复。
- **节点图**：参数、时间、数学公式、对象属性绑定；拖动与连线；拒绝循环依赖。
- **积木**：开始、参数动画、等待、交互暂停、重复、并行。点击“应用到时间轴”替换现有时间轴；节点图独立负责对象关系。
- **代码扩展**：可选 JavaScript，通过 `t`、`params`、`objects` 修改现有对象；独立 Worker 执行，超时停止。
- **保存**：浏览器自动保存当前草稿、导入 / 导出 `.anyvis.json`、撤销 / 重做、演示模式。

## 先试这条工作流

1. 默认示例中按空格播放，4 秒处暂停。
2. 拖动“半径”，观察参考圆、运动点和正弦曲线联动，点击继续。
3. 在“节点”页修改公式或连接；在“时间轴”页拖动动画片段。
4. 在“积木”页调整顺序，点击应用；重新播放观察新的暂停位置。
5. “新建 → 三维空间 → 打开示例”，拖动旋转视角。
6. 导出项目，再通过“打开”导入，检查场景、节点和积木仍在。

手动参数覆盖是暂时的探索状态。可以“保存为初始参数”，但已有动画轨道仍会按自身起止值驱动它。脚本在导入或重新打开草稿后均保持关闭，需要显式启用。

## 设计边界

本版是可扩展编辑器的起点，**不是“任意科学动画”完整实现**。对象种类有限；曲线固定采样 `x ∈ [0, 2π]`；没有 LaTeX 排版、物理求解器、3D 网格导入、复杂粒子系统、可复用子图、Manim 接入、视频输出或独立 HTML 课件导出。三维模式目前支持视角交互和数值编辑，没有 Unity 式变换操纵柄。节点图与积木分别表达关系和编排，暂不互相转换。

手动编辑时间轴不会反向重写积木；重新应用积木会覆盖时间轴。若同一参数存在重叠轨道片段，以开始时间更晚的片段为准，起点相同按项目数组中较后的片段为准；积木并行编排会直接拒绝同参数重叠。

代码扩展只能修改现有对象的变换、颜色、可见性。Worker 是防卡死隔离，**不是运行不可信代码的安全沙箱**；不要启用来历不明项目的脚本。物理模拟等依赖历史状态的计算不在当前确定性播放器保证范围内。

项目只使用本地浏览器存储，尚无账户、云同步或服务端。项目文件是恢复与迁移的方式。详细架构、验证状态和下一步见 `docs/`。

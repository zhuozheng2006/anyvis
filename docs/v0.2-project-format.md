# AnyVis v0.2 项目与编译契约

当前文件描述已实现代码，区别于完整产品设计中的未来目标。项目包含 **78 种积木定义**；这是当前目录数量，不是对 Manim 公共 API 的覆盖率。绘制、形变、文字、公式、参数关系和三维都生成原生 Manim Python。

## 项目结构

```ts
interface Project {
  schemaVersion: 2;
  id: string;
  name: string;
  scene: {
    dimension: '2d' | '3d';
    background: string; // #RRGGBB
    width: number;      // 输出视频像素，非数学坐标
    height: number;
    fps: number;
  };
  actions: Action[];
  workspace?: unknown; // Blockly 布局元数据；actions 是语义权威
}
interface Action {
  id: string; // 稳定积木 ID，用于定位编译和渲染错误
  type: string;
  fields: Record<string, string | number | boolean>;
  children?: Action[];
  branches?: Action[][];
}
```

默认场景为 1920×1080、30 fps；运行器使用高 8 个舞台单位，并按宽高比设置舞台宽度。预览可以降低像素分辨率，但不改变最终求值帧率。

`validateProject(value)` 严格检查版本、场景、积木类型、字段名、枚举、数值范围、重复 ID 和嵌套深度，并根据目录补充省略的默认字段。它返回规范化项目，错误时抛出中文异常。旧 v0.1 JSON 不会被静默重新解释。

## 目录与界面

`catalog.ts` 导出 `BLOCK_CATALOG`、`BLOCK_CATEGORIES`、`getBlockDefinition(type)` 和 `createAction(type, overrides)`。每个条目包含中文标签、分类、字段、默认值、说明、原生对象种类以及三维 / 扩展权限标志。`reference` 元数据区分对象引用、名称列表和数学表达式，供编辑器安全重命名。

创建类积木默认带出场效果和时长。`appear` 为 `create / write / fade / none / hidden`：分别播放原生 Create、Write、FadeIn、直接显示或仅构造。创建与显示仍有独立语义，初学者可以用一个积木完成两者。隐藏目标常用于后续 Transform。

对象以名称作为当前版本的工程内引用，编译成 Python `objects` 字典项；名称不会拼接成 Python 标识符。编辑器重命名必须同步所有引用和相关表达式。后续采用独立对象 ID 的迁移需显式提升 schema，不能只修改显示名后破坏现有项目。

## 编译结果

`compileProject(project)` 返回：

```ts
{
  code: string;                          // 定义 AnyVisScene
  sourceMap: Record<number, string>;      // Python 1-based 行号 → 积木 ID
  duration: number | null;               // 估算秒；任意代码返回 null
  diagnostics: Diagnostic[];
  requiresTrust: boolean;
}
```

存在 `severity: 'error'` 时禁止启动渲染；失败代码不应作为“尽力运行”执行。代码扩展可以包含任意 Python，单独要求显式信任；导入项目不自动授权。数学表达式使用独立白名单语法，不使用 Python `eval` 或字符串属性访问。LaTeX 公式只允许常见数学命令和排版环境，文件读写、宏定义及未识别指令会被拒绝。

## 已实现的执行约束

- 普通动作依次执行，`parallel` 生成一个真实 AnimationGroup。并行时长取最大值，不取总和。
- 同时执行中支持单个动画、带动画出场的对象构造及嵌套同时执行；多步顺序分支暂不支持，避免提前构建目标状态改变语义。
- 同对象或组合成员的重叠写入被拒绝。用户应分步执行，不会被静默改为任意覆盖。
- Transform 保留源对象身份；ReplacementTransform / TransformMatchingTex 之后默认要求后续使用新对象。显式“直接显示”可重新加入旧对象。
- 参数由 ValueTracker 保存，动态点、线、函数、数字与切线通过原生 updater / always_redraw 更新。轨迹使用 TracedPath，依赖真实历史执行。
- `wait` 是普通自动播放停留，不是观众交互暂停。
- 数学表达式支持 `+ - * / % ^ **`、常见三角 / 指数 / 对数函数、`pi/e`、当前自变量及已有参数。隐式乘法需写成 `*`，不接受属性、索引、字符串或任意函数调用。
- 场景最多 500 块原始积木、12 层嵌套；展开后最多 2000 步和 10 分钟。数轴与黎曼和另有限量，避免意外生成数十万对象。
- 三维积木只在三维场景允许。当前三维场景采用 ThreeDScene，二维采用 MovingCameraScene；没有宣称已经支持所有相机或 Scene 子类。

## 当前边界

尚未实现通用资产导入、自定义视觉函数、无限制 API 自动积木生成、条件与通用列表编程、任意 Python 到积木反编译、按任意时间恢复运行栈、完整 API 对照验证。高级代码入口不是这些能力的原生积木替代品。

标准模板实际渲染与视觉检查记录由模板目录和主验证文档维护。核心单元测试检查类型/引用、对象身份策略、并行时序、名称注入、数学与 LaTeX 边界、扩展权限和展开预算；仅通过单元测试不等于画面验收。

## 独立 Python 导出

`exportStandalonePython(project)` 先执行结构验证与编译验证，错误时拒绝导出。独立文件包含明确的 Cairo 渲染器、像素宽高、`frame_height=8`、`frame_width=8*width/height` 与项目 fps，使方形 / 竖屏和非默认帧率不依赖 Manim CLI 默认值。

内部预览仍使用原始 `compileProject` 代码，由 Worker 控制实际预览像素；独立导出设置不会污染内部预览任务或缓存。导出文件注明可用 `python -m manim render --format webm your_scene.py AnyVisScene` 运行；提供 libx264 的环境也可使用 MP4。文件不安装编码器，也不隐含复制应用的 WebM 转码机制。复现视觉效果仍需同版本 Manim、字体与公式环境。

已额外用真实 CLI 验证一份竖屏独立导出：不传尺寸或帧率参数，视频实际为 270×480、24 fps、12 帧，符合项目的 0.5 秒场景设置。

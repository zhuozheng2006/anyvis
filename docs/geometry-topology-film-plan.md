# 《形状不只一种看法：从几何走向拓扑》30分钟制作方案

状态：**可进入分镜与 AnyVis 项目编排的内容设计稿**。本文件不代表影片已经制作、渲染或完成用户测试，也不预先宣称 AnyVis 比直接写 Manim 更快。规划基于当前 97 种原生积木，禁止以 Python 扩展块代替产品能力验证。

## 1. 观众、目标与教学链

面向接触过高中坐标、勾股定理的本科入门观众，不要求学过拓扑、群论或线性代数。影片以中文字幕和图旁解释为主，**静音观看也必须能理解**；配音可后续增加，但不能成为补足缺失推理的依赖。

全片反复使用同一条判断流程：**明确研究对象 → 规定允许的变化 → 观察保留的信息 → 给出映射或不变量作为证据 → 检查证据的适用范围**。主角从圆周、三角形、点线网络逐步过渡到曲面；新概念由上一章未能回答的问题引出，不做术语巡展。

完成后，观众应能：区分全等、相似与同胚；用可逆拉伸说明简单同胚；正确使用平面图欧拉公式并说明外部面；区分把手、边界和定向性；知道同一个欧拉特征数不足以判定任意空间同胚；知道同胚与环境同位研究的问题不同。

## 2. 字幕、动作与30分钟的时间预算

总长严格规划为 **1800秒、6章、72个节拍**。单拍严格25秒；表中①②是先后出现的字幕卡，不能一次全堆到屏幕。它们是需要保留的核心表达，成片可拆成三张更短的卡，不得删去数学前提换取漂亮画面。

- 首次出现的概念按约 **2.8–4个汉字/秒**安排，属于本项目的制作起点，最终由静音试看来校准；这不是引用某项阅读速度研究。每拍两轮正文合计约65–100字，通常每轮约30–50字，停留约11–13秒；长句应分为两行，首次概念可再分两次出现。
- 公式首次出现至少留6–8秒解读；字幕必须说清符号含义。公式较长时，替换一部分正文，不在正文之外再额外塞一段文字。
- 两轮字幕不机械平分12.5秒。按各轮字数分配约22–24秒可读时间：例如56字给约14–15秒、28字给约8秒，图形在字幕期间同步呈现相关变化。两行排版应按语义断句，不能靠缩小字号容纳长句。
- 25秒典型节拍：0–4秒提出问题并定位对象；4–12秒呈现第一步；12–21秒说明第二步并改变一处图形；21–25秒验证或作一次预测。字幕可在相关动作期间保留；同时只让一个区域承载新信息。
- 全部72拍统一25秒，以两轮字幕与阶段性动作承载内容；复杂证明拆到相邻节拍，不压成一张长卡。每个节拍至少有一次有教学意义的状态变化。相机空转、背景粒子、重复绘制标题不算教学状态变化。
- `wait` 可用于阅读，不能机械地把每拍补成固定时长。单次纯停留通常2–8秒；超过10秒的无变化画面必须有明确的思考题和保留中的可读材料，并经试看确认。禁止空白或无信息定格凑满30分钟。
- 每章约24–30张主字幕卡，另有少量短图注。图注用于命名和对应，不能把未经解释的结论压成小字。目标为5,000–6,000字量级的有效正文；字幕定稿后统计实际字数与每卡持续时间，不以这个估计伪装已测结果。
- 成片建议1920×1080、30fps；正文约36–42px视觉等效、图注28–32px、章节标题48–56px。现有 `text.fontSize` 是 Manim 参数，不直接等于视频像素，必须用1080p样帧量测和静音试读校准。字幕区固定占底部约20%，三维内容不进入这个区域。
- 颜色保持身份：原对象青绿、对应对象紫色、当前证据金色、反例警示橙红。颜色必须配合字母、线型或文字，不能成为唯一辨认手段。全片避免将绿色等同“永远正确”。

## 3. 72个教学节拍

时间均为成片全局时间，已经包含章节切换；不要在每章外额外插入片头而使总长超过30分钟。`积木`列表示当前目录中实际存在的类型，不要求每拍创建所有列出的类型。反复出现的对象应保持身份与名称，字幕退出后再进入下一张。

### 第一章：先约定，什么才算“同一种形状”？

学习结果：能在比较前指出研究对象与允许的变换。前置只需认得圆、方形、长度。

教学推理：从直觉分组开始，让同一对图形在不同规则下得到不同答案；本章不抢先背同胚定义。

### 第二章：距离和角度，怎样把形状约束住？

学习结果：能用具体坐标判断平移、旋转、相似、剪切的区别，并知道可逆性为何重要。

教学推理：固定同一个直角三角形，连续修改规则；每一个公式都回答上一拍留下的问题。

| 2.01 · 05:00–05:25（25秒） | 给形状一个可核对的模型 | 显示A=(0,0)、B=(3,0)、C=(0,2)，画三条边；坐标与标签分批出现。 | ①只靠肉眼容易误判。我们把三个顶点放进坐标系。接下来所有数值都从这三个坐标核对，让每次变化都有同一参照。②后面的每次变化，都追踪这三个点，而不是换一张陌生的图。 | `axes` / `dot` / `line` / `text` |
| 2.02 · 05:25–05:50（25秒） | 长度怎样从坐标得到？ | 先突出水平边3、竖直边2，再揭示斜边√13；逐项连到距离公式。 | ①水平与竖直差分别是3和2。把公式中的两个坐标差分别与图上的水平、竖直距离对照起来。②勾股定理给出斜边√13；一般距离也由两个坐标差决定。 | `brace` / `formula` / `matching_tex` / `indicate` |
| 2.03 · 05:50–06:15（25秒） | 平移为什么保距？ | 三点加上相同位移(1,−1)，原图作为低透明参照；公式中的位移项同色抵消。 | ①每个点都加上同一位移，两个点的坐标差不会改变。可以任选另一对顶点重复计算；相同位移总会在相减时消去。②距离依赖坐标差，因此平移保留距离，不只是看起来没变。 | `group` / `copy` / `shift` / `formula` |

| 2.05 · 06:40–07:05（25秒） | 统一放大保留了什么？ | 复制三角形并以2倍放大；长度3→6、2→4、√13→2√13，比例卡不变。 | ①统一放大使每条长度乘2，角度与边长比例不变。②所以相似比全等更宽松：它允许尺寸改变。比较对应边的比值，而不是只凭放大后的图形更占屏幕来判断。 | `copy` / `scale` / `formula` / `matching_tex` |
| 2.06 · 07:05–07:30（25秒） | 面积会以同样倍率改变吗？ | 用3×2矩形的一半说明原面积3；放大后的6×4矩形一半面积12。 | ①长度翻倍时，横向和纵向都翻倍。可以先数覆盖矩形的单位方格，再取其中一半核对这个结果。②三角形面积从3变成12，是原来的4倍，而不是2倍。 | `rectangle` / `line` / `set_style` / `formula` |

| 2.10 · 08:45–09:10（25秒） | 压扁的瞬间发生了什么？ | 把横向倍率a从1减到0.2，再用单独反例画a=0；标记左右重合点。 | ①只要a不为零，就能沿横向除以a还原。我们把不可逆的零倍率单独停下来检查，不让它混在流畅动画里。②到了a=0，不同点合在一起，恢复原位置的信息丢失了。 | `tracker` / `animate_value` / `dynamic_dot` / `line` / `formula` |
| 2.11 · 09:10–09:35（25秒） | 先预测，再核对 | 三张操作卡“旋转”“统一缩放”“剪切”；给出长度、角度、面积三个待选格，逐格揭晓。 | ①先判断哪种操作一定保留长度，哪种保留角度。判断时只依据已经解释的操作定义；一个特殊图形偶然不变还不够。②再检查剪切：这个例子保面积，但不能据此把它叫作刚体运动。 | `text` / `rectangle` / `reveal_group` / `color` |
| 2.12 · 09:35–10:00（25秒） | 留下通向拓扑的问题 | 撤去标尺，保留点的对应与邻近点；标题切换为“如果不再要求保距呢？” | ①我们已经看到：失去精确尺寸，并不必然失去所有结构。②接下来要问，点怎样对应，才能既不撕裂，也不合并？把刚才的标尺结论暂时放到一边，改为检查哪些点对应到哪里。 | `fade_out` / `dynamic_dot` / `text` |

## 4. 可实现画面的具体构造与禁区

这些是分镜的实现约束，不是 Manim 代码。数学表达式可直接填入现有积木字段；未经试渲，不把“表达式能输入”写成“视觉效果已验证”。

### 4.1 现有能力与项目切分

- 交付结构化字幕与镜头数据：`examples/geometry-topology/storyboard.json`，结构为 `chapters[{title,question,beats:[{title,caption1,caption2,visual,point}]}]`。每章12拍，每拍25秒，`point`是审校重点，不应再当第三段字幕堆到屏幕。两轮正文当前合计5,530个字符（含标点与数学记号），逐拍约65–100字符；最终以实际排版和静音试读为准。
- 当前单项目上限500个积木、场景预算10分钟，因此制作6个5分钟章节项目，再拼接为30分钟影片；不能生成一个1800秒项目后绕开验证。优先控制每章在约250–420块，不预先假定这一估计已经通过编译。超限时按教学镜头拆成多个合法项目并保留原全局时间。
- 场景维度在项目级固定。第1、2章可使用2D；第3、4章可把局部三维插镜单独渲染后按分镜拼接；第5章使用3D主场景；第6章用2D复习卡并引用自己已经渲染的三维片段。另一可行方案是整章使用3D场景，平面部分用固定正视镜头。不得在同一项目中假装有一个不存在的“切换维度”积木。
- 三维章节的字幕、公式与章标题使用 `fixed_in_frame`；讲解期间关闭 `ambient_rotation`，仅在观察空间结构的镜头里短时缓转。视角切换应服务于遮挡检查，而非持续制造视觉运动。
- `surface` 和 `parametric_curve` 是创建时采样的曲面/曲线；不要假定引用tracker后就能逐帧重新生成它们。动态点与二维动态线可用 `tracker`、`dynamic_dot`、`dynamic_line`、`animate_value`。完整动态曲面的更新不在此次97块能力内。
- `graph` 的当前布局为圆形或树形，不能依赖任意坐标、任意逐边编辑、自动数面、自环或多重边接口。第4章的主图用独立 `dot`、`line` 与标签构造；增删边就是明确增删对象，V/E/F是经人工审校的字幕计数，不冒充通用图算法。
- 短字幕与公式可用 `text`、`formula`、`write`、`fade_in`；数字更新优先替换独立数字/短公式，不把整段中文交给 `matching_tex`。后者只用于适合公式匹配的 `MathTex` 对象。

### 4.2 圆周、椭圆与方形边界

圆周与方形部分默认填充不透明度为0，图旁常驻“只研究边界”；圆盘与圆环部分则明确填充整个区域。填充是视觉约定，不能靠换色偷偷切换数学对象。

- 圆到椭圆：映射 `f(x,y)=(2x,y)`，逆映射 `f⁻¹(x,y)=(x/2,y)`。用 `apply_matrix` 配 `[[2,0],[0,1]]`、再用逆矩阵验证形状返回；代表点用同色标签追踪。展示的是一个有明确证明依据的例子。
- 单位圆周到边长2、以原点为中心的方形边界：令 `m(t)=max(abs(cos(t)),abs(sin(t)))`，对应点为 `(cos(t)/m(t), sin(t)/m(t))`。`m(t)`始终不为0；反向按射线归一化到圆周。无需让初学者记住公式，主画面以射线的一对一交点为证据，公式只作图旁可核对说明。
- 可用 `parametric_curve` 创建静态方形边界轨迹，用 `dynamic_dot` 随参数t沿对应点运动。以 `tracker` 名如 `angle` 代替保留变量名 `t`。完整轮廓的 `transform` 仅作视觉辅助，不把软件对控制点的插值称为该显式映射。
- 压扁反例必须分别标清：`(x,y)→(0,y)`合并左右点，`(x,y)→(x,0)`合并上下点。不要画错被合并的点，也不要把退化后的线段称为椭圆。

### 4.3 三角形与欧拉图的坐标账本

第2章主三角形为A=(0,0)、B=(3,0)、C=(0,2)，三边3、2、√13，面积3。90°旋转采用 `(x,y)→(−y,x)`；2倍缩放后三边6、4、2√13，面积12；剪切采用矩阵 `[[1,1],[0,1]]`，C到(2,2)，AB仍长3、AC变2√2、A角由90°变45°，面积仍3。屏幕排版可以整体平移缩放，但图旁声明的数学坐标以同一坐标系为准。

第4章图形取A=(−2,−1)、B=(2,−1)、C=(2,1)、D=(−2,1)，边AB、BC、CD、DA、AC，不含BD。状态账本必须严格遵守：

| --- | ---: | ---: | ---: | --- |
| 四边形加AC | 4 | 5 | 3 | 连通；两个内部面和一个外部面。 |
| 在AB中点加P并把AB改成AP、PB | 5 | 6 | 3 | 细分不改变区域数。 |

### 4.4 曲面参数与定向演示

- **球面**：用 `sphere`，字幕称“球面/外壳”。实体剖面只作对象范围对照，不作后续曲面计数对象。
- **环面**：`surface` 可填 `x=(2+0.65*cos(v))*cos(u)`、`y=(2+0.65*cos(v))*sin(u)`、`z=0.65*sin(v)`，u、v均从0到2π；先用约24–32网格精度试渲，避免为长片无条件拉到最高精度。x/y表达式可以整体加减常量作并排定位。
- **开口圆柱侧面/普通环带**：`surface` 用 `(2*cos(u), 2*sin(u), v)`，u从0到2π，v从−0.5到0.5。不要使用默认含端盖的 `cylinder` 代表这个有两条边界的曲面。平面圆环用 `annulus`，它与该侧面同胚；片中应说明这两个模型表达同一种环带。
- **莫比乌斯带**：`surface` 用 `x=(2+v*cos(u/2))*cos(u)`、`y=(2+v*cos(u/2))*sin(u)`、`z=v*sin(u/2)`，u从0到2π、v从−0.5到0.5。数值网格在参数边缘可能有可见缝线，缝线是绘图采样接缝，不是数学边界；字幕不得顺着它错误地数出第二条边界。
- **莫比乌斯带的一条边界**：把v固定为0.5，用 `parametric_curve` 让参数从0到4π，才遍历全部一条边界；0到2π只走到了另一参数边，不是已经闭合。普通环带的上下两条边界分别以v=±0.5、u从0到2π表示。
- **局部朝向标记**：中心点取v=0，横向红蓝两点取v=±0.22；让共同参数 `angle` 从0走到2π。在莫比乌斯带上，红蓝两点回到起始中心旁时交换位置；普通环带上不交换。必须同时给出沿中心线前进的切向指示（起点附近用静态箭头和“前进方向”图注即可），以“前进+横向”组成局部朝向，不能只把两颗彩点交换称为完整定义。
- 当前 `dynamic_line` 只直接支持二维线段的动态端点，不可假称已有三维动态法向箭头。三维标记可由 `dynamic_dot` 的三个表达式实现；若此布局试渲不清楚，退回**二维粘边图+起点/终点局部标记对照**，保留同一数学论证。不要临时添加任意Python掩盖产品限制。
- **Klein瓶**：在方形粘边图中，一对相对边方向相同、另一对相反；边与角按识别关系计数，得到χ=0。此次不必展示复杂三维自交模型。若展示任何这种投影/浸入模型，必须标“图中的自交不表示这些点在抽象曲面中相同”。莫比乌斯带有1条边界，Klein瓶与射影平面无边界，不能混称。
- **普通圆结与三叶结**：三叶结可用参数曲线 `(sin(t)+2*sin(2*t), cos(t)−2*cos(2*t), −sin(3*t))`，t从0到2π；圆结用三维平面圆周。两者分别创建并旋转观察，不做互相 `transform`。若3D细线遮挡不能可靠区分上下穿越，则保留静态标注与引用结论，不能凭模糊交叉制造错误的结图证据。

## 5. 数学审校的硬性要求

1. **对象始终明确。**圆周/圆盘、球面/实心球、线框图/带二维面的空间分别命名。不能从边界形状的动画直接推断填充区域的结论。
2. **同胚定义完整。**一一且到达目标全部点，正反向都连续。连续映射或流畅变形不自动满足这一条件。[S1]
3. **同胚与环境同位分开。**后者让整个环境空间形成始于恒等映射的连续自同胚族。结作为抽象空间都同胚于圆周，并不意味着其嵌入环境同位。圆结与三叶结不环境同位是引用结论，非本片动画所证。[S2]
4. **欧拉公式写前提。**有限、连通、平面无交叉嵌入，外部面计入F；删边证明只能沿回路删去不会破坏连通的边。计数变化与证明过程对应，不把任何图都写成等于2。[S3][S4]
5. **χ的对象层级清楚。**一维图是V−E，二维有限胞腔分解是V−E+F；必须正确处理识别后的顶点与边。分解独立性是已有定理，不声称只凭一次计数就完成了一般证明。[S5]
6. **反推要克制。**同胚推出χ相同；χ不同排除同胚。相同χ不能一般地确认同胚；环面与Klein瓶给出闭曲面反例，普通环带与莫比乌斯带给出带边界反例。[S6]
7. **曲面公式保留所有条件。**连通、紧致、可定向曲面有 `χ=2−2g−b`，b=0时才是闭曲面版本；这里“闭”指紧致且无边界。不可定向、连通紧致曲面若由k个射影平面连通和构成，则 `χ=2−k−b`；k不是可定向把手数。后一公式仅留在图旁补充/参考资料，避免在25秒内引入未解释的一串术语。[S5][S6][S7]
8. **分类定理只在范围内使用。**连通紧致曲面可由边界分支数、可定向性和χ联合分类；不能把这个结论推广到任意维数、任意空间或三维嵌入类型。[S6]
9. **曲面的“洞”不用一个含糊数字代替。**分别说连通分支、边界分支和可定向把手数。球面b=0、g=0、χ=2；环面b=0、g=1、χ=0；圆盘b=1、g=0、χ=1；普通环带b=2、g=0、χ=0；莫比乌斯带b=1、不可定向、χ=0。[S6][S7]
10. **视觉演示不越权。**形状插值、三维阴影、相机转动、曲面自交投影都不是自动的数学证明。画面要注明它是在显示定义、检验具体例子，还是援引一个本片未证明的定理。

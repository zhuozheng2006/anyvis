# 第五轮：素材操作与保存、导出验收

本轮以 `b41618d` 为基线，修复素材操作的工程校验和草稿打包问题，并通过真实浏览器完成上传至成片的流程。用户要求成果继续提交 `main`，不保留待合并 PR。

## 修复

- 素材库原先可写入第 501 个动作或第 101 份素材，导致后续校验、重开失败。上传图片、复用图片和添加配音现统一经过工程结构及编译差异校验；失败保留原工程，在素材库显示原因。
- 上传仍合并到最新编辑状态，切换作品后丢弃旧上传结果。Enter/Space 可以打开文件选择器，上传中禁止重复打开。
- 带素材的未完成草稿原先会因生成 Python 失败而无法保存。普通保存现在保留 JSON 和素材，缺少源码时在包内说明；“导出源码”仍严格拒绝编译错误，并在读取素材前报错。
- ZIP 保存检查 JSON 的 8 MB 限制，以及包含源码、说明和文件头的完整包 128 MB 限制。说明改为导入整个 ZIP，以同时恢复原始素材。
- 修正旧对象管理器测试中不符合生产规则的素材 ID、缺失图片尺寸；没有放宽工程校验。

浏览器测试作品 `AnyVis-Media-QA-20261109` 使用自己生成的蓝色圆形黄色星标 SVG，以及 2 秒、660 Hz、24 kHz 单声道 WAV。设置配音延迟 0.5 秒、源入点 0.25 秒、长度 1 秒、增益 −6 dB、无背景音乐；两个等待积木使作品总长为 2 秒。ZIP 内两个素材的 SHA-256 均核对一致，包含 `scene.py`；重新导入后恢复图片、两份素材与 2 秒真实预览。验收后切回原作品并恢复钢琴默认偏好。

下载的 MP4 实际解码为 H.264/AAC、1280×720、30 fps、60 帧。画面中的黄色星标和蓝色圆形均保留；配音检测起止约 0.503–1.503 秒，主频 660 Hz，前后区间静音。相对 PyAV 单声道转立体声后施加 −6 dB 的参考信号，测得音量误差约 0.045 dB。完整数据见 [视频测量](review-evidence/2026-11-09/round5-ui-video.json)。

## 边界与后续

浏览器流程是在本机 Chrome 完成，桌面宿主测试不能替代三个操作系统的人工安装交互验收。本轮没有发布新的安装器。有效 API 行为证据仍为 1,538 / 2,293，未验证 755；本轮没有增加 API 覆盖，也没有完成真实音频频谱分析或自定义缓动应用。后续可继续补齐这些能力及更长作品的真实渲染验证。

# 可编辑模板

模板使用与编辑器相同的版本化积木项目，每个步骤都可以展开、调整、删除或重新排列。全部模板通过原生积木构成，没有隐藏的 Python 扩展块。

`index.ts` 导出 `templateCatalog` 与 `getTemplate(id)`。后者返回独立副本；修改模板不会污染模板目录或其他项目。`public/templates/` 的 SVG 是选取作品时使用的示意图，不是实际视频关键帧。点击预览后，舞台呈现原生 Manim 渲染的结果。

## 模板内容

| 模板 | 可修改的重点 | 创作能力 |
| --- | --- | --- |
| 第一段动画 | 形状、文字、颜色、动作和时长 | Create、Transform、旋转、缩放、并行与文字 |
| 单位圆与正弦 | 参数 theta、转速、半径与颜色 | ValueTracker、表达式绑定、TracedPath |
| 割线趋近切线 | 函数、切点、点间距 h | 动态点、动态直线、参数数值与切线 |
| 公式连续推导 | 四个公式与每步停留 | MathTex、TransformMatchingTex |
| 矩阵改变空间 | 矩阵、向量、图形和逆变换 | NumberPlane、Matrix、组合与 apply_matrix |
| 图的广度优先搜索 | 指定图、顶点访问步骤与标注 | 图结构、树形布局、逐顶点样式动画 |
| 三维函数曲面 | 曲面表达式、采样、镜头与标注 | Surface、ThreeDAxes、相机环绕与固定文字 |

BFS 模板演示给定七顶点图的一条合法访问顺序，并不自动根据任意新图计算 BFS。更改图结构后，需要同步调整访问步骤。矩阵模板中的正方形是参考图形，不假称单位正方形；三维曲面与坐标轴采用相同的世界坐标比例。

## 已执行的验证

2026-11-07 使用模板经 `compileProject` 生成的 Python，在 Manim Community **0.20.1 / Cairo** 上实际渲染。输出格式为原生 VP9 WebM，解码后检查尺寸、帧率、总帧数，并查看中间及结尾关键帧。

| 模板 | 分辨率 / 帧率 | 实际时长 / 解码帧数 | 结果 |
| --- | --- | --- | --- |
| first-animation | 640×360 / 30 fps | 15.4 秒 / 462 | 通过 |
| unit-circle | 640×360 / 30 fps | 15.7 秒 / 471 | 通过 |
| tangent | 640×360 / 30 fps | 14.8 秒 / 444 | 通过 |
| formula | 640×360 / 30 fps | 15.6 秒 / 468 | 通过 |
| linear-map | 640×360 / 30 fps | 16.2 秒 / 486 | 通过 |
| bfs | 640×360 / 30 fps | 14.1 秒 / 423 | 通过 |

检查中发现的顶点高亮标签消失和三维镜头遮挡文字已修正，并重新渲染确认。每段动画的时间会被 Manim 量化到帧，因此动作时长之和与最终媒体时长可能相差少量帧。

`templates.test.ts` 的 9 项检查覆盖所有项目的有效性、原生积木编译以及模板副本隔离。它们不替代真实渲染与人工画面检查；以上结果也不代表全部 Manim API、所有编辑方式、其他引擎版本或跨平台环境已通过。

## 内置真实预览资产

`public/templates/rendered/` 随应用提供七段轻量原生 Manim 预览（VP9 WebM）与从这些视频解码得到的 PNG 海报，总计约 **1.99 MB**。用户首次打开即可观看；它们必须标为“内置示例预览”，不是实时编辑结果。项目动作、参数或场景改变后应标记画面过期，只有重新渲染才能声称匹配当前作品。

`templateCatalog` 提供 `previewUrl`、`posterUrl`、`previewKind: 'prerendered-native-manim'` 和 `previewEngine: 'Manim Community 0.20.1'`。`manifest.json` 记录每段媒体的引擎、帧数、大小、时长、海报时间点、源码哈希、项目哈希与媒体哈希。BFS 使用最终树形布局且顶点标签保持对比度；三维预览使用修正后的镜头缩放。

更新模板时，先重新编译并使用相同求值帧率原生渲染，再人工检查代表帧和最终状态；拷贝最终完整视频并从中提取海报，更新清单。模板测试会检查当前编译源码、IR 与内置媒体是否仍与清单一致，避免模板已经修改而预览仍然过期。更换字体、渲染器或引擎版本也应重做验证。

其他本地 QA 媒体、逐动画缓存与日志不提交。
